== Verify RHACS CLI access

`ROX_CENTRAL_ADDRESS` and `ROX_API_TOKEN` are already set on the bastion.
`roxctl` reads the token from the environment. Do not pass `--token`.

. Set `ROX_ENDPOINT` so `roxctl` picks up the address automatically:
+
[source,bash]
----
export ROX_ENDPOINT="$ROX_CENTRAL_ADDRESS"
----
. Verify CLI access:
+
[source,bash]
----
roxctl central whoami
----
+
Expected output includes an Admin (or equivalent) role.
