== Access the bastion host

SSH into the bastion host using the credentials from the Showroom dashboard:

[source,bash]
----
ssh lab-user@<bastion-host> -p <port>
----

NOTE: Replace `<bastion-host>` and `<port>` with the values shown on your Showroom dashboard under *Bastion Host*.

== Discover your console URLs

On the bastion, run:

[source,bash]
----
echo "OpenShift Console: https://$(oc get route console -n openshift-console -o jsonpath='{.spec.host}')"
echo "RHACS Console:     https://$(oc get route central-reencrypt -n stackrox -o jsonpath='{.spec.host}')"
echo "Keycloak Console:  https://$(oc get route keycloak -n keycloak -o jsonpath='{.spec.host}')"
echo "Splunk Console:    https://$(oc get route splunk-web -n splunk -o jsonpath='{.spec.host}')"
----

Open each URL in your browser. Credentials for this Showroom:

|_(see below)_

NOTE: The OpenShift and RHACS admin password was sent to you in the Showroom provisioning email. Keycloak admin credentials are retrieved from the cluster in Exercise 3. You do not need to log in to Keycloak now.

== Verify RHACS CLI access

`ROX_CENTRAL_ADDRESS` and `ROX_API_TOKEN` are already set on the bastion.

[source,bash]
----
export ROX_ENDPOINT="$ROX_CENTRAL_ADDRESS"
roxctl central whoami
----

NOTE: Expected output includes an *Admin* (or equivalent) role. Do not pass `--token` -- `roxctl` reads it from the environment.

== Clone the lab repository

[source,bash]
----
git clone https://github.com/john-johansson/acs-labs.git
cd acs-labs
----

== Full reset (optional)

If you have run these exercises before on this Showroom and want a clean starting point, run the cleanup script from the cloned repository:

[source,bash]
----
bash scripts/s2-cleanup.sh
----

The script removes all lab-created resources (report configs, notifiers, policy clones, SAC objects, Keycloak realm, and trigger pods). It is idempotent and safe to run multiple times.
On a fresh Showroom you can skip this step.
