= Lab summary
:navtitle: Lab summary

In this session you explored RHACS operational capabilities beyond the policy engine:

* *Vulnerability Management*: navigated Results, compared OS vs language findings with Scanner V4, and compared severity across demo images such as juice-shop and nginx (Exercise 1).
* *Reporting*: created a scoped PDF/CSV report and generated it on demand (Exercise 2).
* *Scoped Access Control and identity*: built Permission Set, Access Scope, and Role, then mapped a Keycloak group for tenant isolation (Exercise 3).
* *Risk and exceptions*: inspected Risk priority, applied a policy scope exclusion, and deferred a CVE with an auditable rationale (Exercise 4).
* *Notifiers*: cloned a system policy, attached a generic webhook, and sent alerts to Splunk HEC (Exercises 5 and 6).

These capabilities are the Day-2 foundation for multi-team visibility, prioritization, and alert routing into the tools teams already operate.

== Reset the environment

To remove all resources created during this session and return the environment to its starting state, run the cleanup script on the bastion:

[source,bash]
----
bash scripts/s2-cleanup.sh
----

The script removes report configurations, notifiers, policy clones, SAC objects (auth provider, role, permission set, access scope), the Keycloak realm, and trigger pods. It is idempotent and safe to run multiple times.
