Working YAML for each session lives in the Antora `examples/` directory.
Clone https://github.com/john-johansson/acs-labs[this repository] onto the Showroom bastion, then `oc apply -f` those files.

== How to use this guide

* **This page is home** — start here, then follow *Next* at the bottom of each page.
* **Navigate with the table of contents** — modules are in the left sidebar.
* **Use the bastion** — run `oc` and `roxctl` on the RHEL bastion.

IMPORTANT: Do not commit tokens, Showroom passwords, or kubeconfigs.

== Adding a topic

. Create a topic overview page under `content/modules/ROOT/pages/`.
. Group its exercises under a new section in `content/modules/ROOT/nav.adoc` (same pattern as *Policy Engine*).
. Put reusable YAML in `content/modules/ROOT/examples/`.
