== Lab objectives

By completing this lab, participants will:

. Navigate RHACS policy management across *Build*, *Deploy*, and *Runtime* lifecycle stages.
. Inspect deploy-time and runtime violations, including forensic process detail.
. Explore the built-in policy library and enable deploy/build enforcement in the console.
. See the difference between *inform-only* deploy policies and *admission-controller rejection* of create requests.
. Understand structural differences between policies created via the ACS GUI / API and Custom Resource Definitions (CRDs) synced as GitOps.
. Build custom guardrails for private registry enforcement, Cosign image signature verification, and fixable CVE thresholds (>= 9.0).
. Integrate `roxctl` CLI checks in pipeline workflows and confirm a non-zero exit code when a deploy policy is set to break the check.
