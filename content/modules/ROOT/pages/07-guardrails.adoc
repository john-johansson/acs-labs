== Task 7.1: Cosign image signature verification

This Showroom already has a Cosign signature integration named *Red Hat*.
Use that ID as a stand-in for an organization release key.
In production you would add the pipeline's Cosign public key under *Platform Configuration → Integrations*.

[source,bash]
----
export SIG_ID=$(curl -sk -H "Authorization: Bearer $ROX_API_TOKEN" \
  "$ROX_CENTRAL_ADDRESS/v1/signatureintegrations" \
  | python3 -c 'import sys,json; d=json.load(sys.stdin); print(next(i["id"] for i in d.get("integrations",[]) if i.get("name")=="Red Hat"))')
echo "$SIG_ID"
sed "s|REPLACE_WITH_SIGNATURE_INTEGRATION_ID|${SIG_ID}|" \
  content/modules/ROOT/examples/cosign-signature-policy.yaml | oc apply -f -
----

`Image Signature Verified By` matches images that are *not* verified by the selected integration.
Do *not* set `negate: true` on that field, or the policy would alert on signed images.

TIP: Compare with the built-in (disabled) policy *Red Hat images must be signed by a Red Hat release key* — same criterion, production-shaped example.
