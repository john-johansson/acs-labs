== Lab objectives

By completing this lab, participants will:

. Deploy declarative CIS compliance profiles via the Compliance Operator (apply from the lab repository) and observe scan results as native Kubernetes CRDs.
. Create a CIS scan schedule in the RHACS UI, compare Coverage with CLI status counts, triage Fail or Inconsistent findings with remediation guidance, and distinguish platform compliance from runtime policies in the same console.
. Generate on-demand compliance audit evidence in the UI and fetch the CSV evidence package from Central on the bastion.
. Audit container listening endpoints at the process and PID level, then correlate them with deployment manifests.
. Visualize multi-tier network topology in the RHACS Network Graph, enable baseline violation alerts, and prove *Unauthorized Network Flow* with controlled probes.
. Detect anomalous cross-namespace traffic from an operations jump host to the payment tier.
. Auto-generate standard Kubernetes `NetworkPolicy` manifests from baselines (after marking unexpected peers anomalous) using the RHACS Network Policy Generator.
. Verify network policy enforcement at the kernel level using TCP probes.

== Compliance and network workflow (reflection)

In production, these exercises chain together:

. The Compliance Operator evaluates CIS benchmarks from a declarative binding (Exercise 1). Students then recreate that CIS schedule in the RHACS UI, triage failing controls with remediation guidance, and distinguish platform compliance from runtime policies in the same console (Exercise 2).
. Scan schedules with delivery destinations automate evidence distribution. On-demand downloads handle ad-hoc audit requests (Exercise 3).
. RHACS Collector maps every open port to an exact process binary (Exercise 4). The Network Graph visualizes active traffic, locks baselines, and proves *Unauthorized Network Flow* alerts (Exercise 5).
. Anomalous cross-namespace traffic is visible in the graph (Exercise 6). Baseline-aware generated `NetworkPolicy` manifests enforce zero-trust microsegmentation at the kernel level (Exercises 7 and 8).
