== Lab objectives

By completing this lab, participants will:

. Deploy declarative CIS compliance profiles via the Compliance Operator and observe scan results as native Kubernetes CRDs.
. Create scan schedules in the RHACS UI, triage failing checks, and work with remediation guidance to prepare for an audit.
. Generate on-demand compliance audit evidence and understand how delivery destinations automate evidence distribution.
. Audit container listening endpoints at the process and PID level, then correlate them with deployment manifests.
. Visualize multi-tier network topology in the RHACS Network Graph and enable baseline violation alerts.
. Detect anomalous cross-namespace traffic from an operations jump host and generate your own anomalous probe to watch it appear in real time.
. Auto-generate standard Kubernetes `NetworkPolicy` manifests from observed baselines using the RHACS Network Policy Generator.
. Verify network policy enforcement at the kernel level using TCP probes.

== Demo application architecture

This session uses the pre-deployed multi-tier medical application. The network exercises focus on three namespaces:

....
   [ frontend/tls-proxy ]
            |
            v
     [ backend/varnish ]
            |  (Port 9001)
            v
     [ backend/api-server ] -----> [ payments/gateway ] (Port 7777)
       |         \                       |          \
       v          v                      v           v
  [ postgres ]  [ backend-atlas ]   [ visa-proc ]  [ mastercard-proc ]
  (Port 5432)   (Port 8080)        (Port 8080)    (Port 8080)

   [ operations/jump-host ] --X--> [ payments/visa-processor ] (ANOMALOUS)
                            --X--> [ medical/patient-db ]      (ANOMALOUS)
....

The `operations/jump-host` represents an unapproved lateral movement source that bypasses the legitimate API gateway tier.

== Compliance and network workflow (reflection)

In production, these exercises chain together:

. The Compliance Operator continuously evaluates CIS benchmarks (Exercise 1). RHACS provides both UI and CLI workflows for managing scans, and links failing controls to specific remediation guidance (Exercise 2).
. Scan schedules with delivery destinations automate evidence distribution. On-demand downloads handle ad-hoc audit requests (Exercise 3).
. RHACS Collector maps every open port to an exact process binary (Exercise 4). The Network Graph visualizes active traffic and locks baselines (Exercise 5).
. Anomalous cross-namespace traffic triggers real-time alerts (Exercise 6). Auto-generated `NetworkPolicy` manifests enforce zero-trust microsegmentation at the kernel level (Exercises 7 and 8).
